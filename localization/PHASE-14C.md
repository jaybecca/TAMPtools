# Phase 14C — Localization & Translation

Adds the remaining six agreed interface languages for this checkpoint:

- Marathi (`mr`)
- Vietnamese (`vi`)
- Telugu (`te`)
- Hausa (`ha`)
- isiZulu (`zu`)
- Turkish (`tr`)

Extends the shared TAMPtools language selector and `/api/i18n` dictionary while preserving the existing three-layer language architecture: Interface Language, Writing Language, and Translation Language.
