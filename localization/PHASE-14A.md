# Phase 14A — Localization & Translation

Interface-language foundation for the first 8 agreed languages:
English (US), English (UK), Chinese Simplified, Spanish, Hindi, French, Arabic, Bengali.

- Language selector supports the 8 Phase 14A languages.
- Locale API and UI dictionaries use explicit language keys.
- English US and English UK are distinct interface locales.
- Arabic enables RTL layout.
- Existing writing/translation language architecture remains ready for later Phase 14 work.
- Remaining 14 interface languages are intentionally completed in later Phase 14 milestones.
