# Phase 30 Translation Coverage

Phase 30 focuses exclusively on the customer-facing interface translation layer.

The translation dictionary is keyed by exact UI phrases and shared i18n keys. Runtime translation covers static elements marked with `data-i18n`, placeholders, ARIA labels, exact visible phrases, and generated shell/tool labels.

Technical identifiers, API routes, database fields, environment variable names, URLs, provider names, file extensions, and code identifiers remain unchanged by design.
